# From Chopped to Cooked: Design and Inference in Physical Environments

This repository contains code, data, and experiments for the CogSci 2026 paper:

> Yang, J., Wu, S. A., & Gerstenberg, T. (2026). From chopped to cooked: Design and inference in physical environments. In *Proceedings of the 48th Annual Conference of the Cognitive Science Society*.

## Repository structure

```
├── project_code/
│   ├── R/                          # Statistical analysis (Rmd + utils)
│   ├── python/                     # Data processing and model pipelines
│   └── experiments/                # jsPsych web experiments
├── data/
│   ├── s1_design_inference/        # Study 1 behavioral + model results
│   └── overcooked_design/          # Study 2 cached analysis objects
├── stimuli/
│   ├── s1_design_inference/        # Kitchen layouts (txt + images)
│   └── overcooked_design/          # Design task configurations
├── figures/                        # Generated figures
├── gym-cooking/                    # Simulation framework (submodule)
└── environment.yml                 # Conda environment specification
```

## Quick start: reproduce paper figures and statistics

All paper figures, tables, and statistics are generated by a single R Markdown file. Pre-computed data files are included so you can knit without running simulations.

```bash
# Install R dependencies (requires R >= 4.0)
# tidyverse, brms, loo, patchwork, ggridges, Hmisc

# Knit the analysis
cd project_code/R
Rscript -e "rmarkdown::render('analysis_cogsci2026.Rmd')"
```

**Note:** The brms model fits (`brms_fit_*.rds`, ~7 GB total) are hosted on OSF due to size. Download them to `data/overcooked_design/model_cache/` before knitting, or the Rmd will attempt to refit the models (which takes several hours).

## Full reproduction from scratch

### 1. Environment setup

```bash
conda env create -f environment.yml
conda activate design-inference
```

### 2. Study 1 — Design inference

```bash
# Find optimal agent start locations (requires gym-cooking)
python project_code/python/s1_design_inference/find_start_locations.py

# Run simulations (local or cluster)
python project_code/python/s1_design_inference/model_runs.py

# Process simulation outputs into CSV
python project_code/python/s1_design_inference/process_model_outputs.py

# Download behavioral data from OSF (requires OSF credentials)
python project_code/python/s1_design_inference/get_behavioral_results.py
```

### 3. Study 2 — Overcooked design

```bash
# Run simulations for all furniture placements
python project_code/python/overcooked_design/get_model_results.py

# Download behavioral data from OSF
python project_code/python/overcooked_design/get_behavioral_results.py
```

### 4. Analysis

```bash
cd project_code/R
Rscript -e "rmarkdown::render('analysis_cogsci2026.Rmd')"
```
