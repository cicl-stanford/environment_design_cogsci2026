# Data

Processed behavioral and model outputs organized by study.

## Structure

```
data/
├── s1_design_inference/
│   ├── behavioral_results/
│   │   └── trial_data.csv          # One row per slider response
│   └── models/
│       └── model_results.csv       # Simulation metrics per trial × config
│
└── overcooked_design/
    ├── behavioral_results/
    │   ├── design_data.csv         # One row per design trial
    │   └── session_data.csv        # One row per participant session
    ├── model_results/
    │   └── placement_utilities.csv # Simulation costs per placement × config × dish
    └── model_cache/
        ├── loo_*.rds               # LOO cross-validation objects (9 files)
        ├── split_half_accuracy_ceiling.rds  # Human split-half ceiling
        ├── h0a_results.rds         # Hypothesis test results
        └── h0b_results.rds         # Hypothesis test results
```

## Data Sources

**Behavioral data:** Retrieved from OSF using `get_behavioral_results.py` scripts. Each script downloads raw experimental data and processes it into structured CSV files.

- Study 1 OSF component: `ykeqp` (inference), `8fjh9` (effort)
- Study 2 OSF component: `ywtf5`

**Model data (Study 1):** Generated by running gym-cooking simulations via `model_runs.py`. The `process_model_outputs.py` script converts raw simulation outputs (pickle files) into the analysis-ready CSV.

**Behavioral data (Study 2):** `design_data.csv` and `session_data.csv` are retrieved from OSF using `get_behavioral_results.py`. The Rmd preprocesses these CSVs directly (parsing placement JSON, joining with simulation utilities) to construct the analysis dataframes.

**Model results (Study 2):** `placement_utilities.csv` contains simulation costs for every possible furniture placement in each design configuration. Generated by `get_model_results.py` using the gym-cooking framework.

**Model cache (Study 2):** Pre-computed objects that are expensive to regenerate.

- `loo_*.rds` (9 files): LOO cross-validation objects for each model variant. Created by brms model fitting scripts (~hours to refit).
- `split_half_accuracy_ceiling.rds`, `h0a_results.rds`, `h0b_results.rds`: Generated by `analysis_cogsci2026.Rmd` on first run and cached for subsequent knits.

**brms model fits:** The Bayesian regression model fits (`brms_fit_*.rds`, ~7 GB total) are too large for git. Download from OSF and place in `overcooked_design/model_cache/` before knitting the Rmd.

## Study 1: trial_data.csv Schema

| Column | Description |
|---|---|
| trial_id | Unique trial identifier (UUID) |
| response_id | Unique response identifier (UUID) |
| game_id | Participant session identifier |
| kitchen_layout_id | Kitchen trial ID (trial_01 through trial_36) |
| trial_order | Presentation order within session |
| condition | Experimental condition (cooks, dish, cooks_effort, dish_effort) |
| question_type | Type of slider question |
| slider_response | Participant's slider value (0-100) |
| rt | Response time in milliseconds |

## Study 1: model_results.csv Schema

| Column | Description |
|---|---|
| trial_id | Kitchen trial ID |
| num_agents | Number of agents (1 or 2) |
| model_type | Planning algorithm (greedy or bd) |
| recipe | Dish type (Salad or SaladOL) |
| seed | Random seed |
| timesteps | Steps to complete task |
